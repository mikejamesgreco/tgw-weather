TGW Weather Help

TGW Weather — The Greco Weather is a lightweight single-file weather comparison tool. It queries multiple forecast providers for the same location and shows their results side by side along with simple consensus values.

How the consensus works

High temperature, low temperature, chance of rain, and wind speed are arithmetic averages of the providers that successfully reported each metric. The range shown beneath each consensus value helps show how much the providers agree or disagree.

Weather providers

Open-Meteo and the U.S. National Weather Service can be used without an API key. WeatherAPI.com, OpenWeather, Visual Crossing, Tomorrow.io, and Weatherbit can be included with personal API keys. A provider can be disabled at any time in Weather Services & API Keys.

API keys and saving settings

Provider enable/disable choices and API keys are saved in this browser using local storage. Keys are not embedded in the distributed TGW HTML file, but browser JavaScript must be able to read a saved key in order to send it to the selected provider.

Location input

You can enter a ZIP/postal code, a city and state, or latitude/longitude. TGW resolves the location first, then sends the same coordinates to each enabled provider so the comparison is based on the same point.

Provider differences

Forecast services use different models, update schedules, grids, and interpretation methods. TGW does not replace any official forecast service; it provides a quick way to compare several independent forecasts and see their spread.

Privacy and local-first design

TGW is designed as a Single-File Local Application (SFLA). The interface runs in your browser. Forecast requests are sent directly to the enabled weather providers. Saved provider settings remain in the browser's local storage unless you clear them.
